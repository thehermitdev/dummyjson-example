
## Step 5 — Add response normalization

Project ทำ:

```text
create input
→ POST /todos/add
→ merge parsed input + response.data
→ todoSchema.parse
→ Todo
```

เหตุผลคือ simulated response อาจต้องรวมกับ known input เพื่อให้ read model สมบูรณ์

## Step 6 — Update response normalization

Project `updateTodo(todo, input)` รับ current Todo เข้ามาด้วย

Flow:

```text
current Todo
+ parsed update input
+ API response
→ merge
→ todoSchema.parse
→ complete Todo
```

นี่ทำให้ fields ที่ API simulation อาจไม่คืนครบยังคงอยู่ใน read model

# Phase 5 — Mutations ตาม Project จริง

## Step 8 — สร้าง `src/features/todos/api/mutations.ts`

Reference:

- [Todos mutations](https://github.com/thehermitdev/dummyjson-example/blob/main/src/features/todos/api/mutations.ts)

Exports:

```text
addTodoMutationOptions(queryClient)
updateTodoMutationOptions(queryClient)
deleteTodoMutationOptions(queryClient)
```

### Add

```text
ทุก cached todos list
→ prepend Todo
→ จำกัดตาม current limit
→ total + 1

detail key
→ seed Todo
```

### Update

Project ใช้ helper `replaceTodo`:

```text
ทุก cached todos list
→ map
→ ถ้า id ตรงกัน replace ด้วย updated Todo

detail key
→ replace Todo
```

### Delete

```text
ทุก cached todos list
→ filter id ออก
→ total - 1

detail key
→ remove query
```

## Step 9 — Reassignment: อธิบายข้อจำกัดโดยไม่เปลี่ยน Project

สมมุติ:

```text
Task #10
userId 5 → userId 8
```

อาจมี cached lists:

```text
["todos", "list", { userId: 5, ... }]
["todos", "list", { userId: 8, ... }]
["todos", "list", { ไม่มี userId, ... }]
```

Implementation Project ปัจจุบันใช้ **broad replacement**: replace Todo ที่ id ตรงกันในทุก cached list

ผลเชิง semantic คือ list ที่ filter `userId: 5` อาจยังถือ Todo object ที่ reassigned เป็น User 8 จนกว่าจะมี lifecycle อื่นมาปรับ cache

สิ่งสำคัญสำหรับ roadmap นี้:

> เรารับรู้ limitation ได้ แต่ **ห้ามเปลี่ยน implementation เป็น predicate-aware reconciliation** ในการ reconstruct เพราะ Project ปัจจุบันยังไม่ได้ทำเช่นนั้น

ดังนั้นให้สร้าง `mutations.ts` ตาม Reference ตรง ๆ

## Common Mistakes

### 1. เปลี่ยนชื่อ resource path เป็น `/tasks`

Project ใช้ `/todos`; Tasks เป็น UI language

### 2. Fetch Users แยกใน Todos feature

Project reuse Users Directory

### 3. Debounce assignee select

Project update select ทันที

### 4. สร้าง custom pagination/delete dialog

Project ใช้ shared components จาก Chapter 00

### 5. เปลี่ยน broad mutation reconciliation เป็น predicate-aware logic

นั่นจะเป็นการแก้ Project ไม่ใช่ reconstruct Project

### 6. `invalidateQueries()` อย่างเดียวหลัง write

DummyJSON simulated writes ไม่ persist แบบ backend จริง Project patch cache โดยตรง
